# Changelog

## 0.1.0 (unreleased)

Initial release. The CLI moved here from `github.com/slidecold/slidecold-go/cmd/slidecold` (slidecold-go v0.1.0).

- `slidecold login`, `logout`, `version`, and a command for every operation of the SlideCold API.
- Prebuilt binaries for Linux, macOS and Windows (amd64, arm64) with signed build provenance.
- `slidecold version` reports the release version (or the module version for `go install`), no longer the SDK's.
